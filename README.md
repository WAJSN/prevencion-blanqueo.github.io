# Prevención del Blanqueo de Capitales

Este proyecto es una campaña informativa y de concientización sobre la **Prevención del Blanqueo de Capitales** desarrollada para el primer semestre de 2025. El objetivo principal es educar y sensibilizar a las personas sobre los riesgos, etapas, consecuencias y medidas de prevención relacionadas con el blanqueo de capitales.

## Características

El proyecto incluye las siguientes secciones clave:

1. **¿Qué es el Blanqueo de Capitales?**
   - Definición del concepto y explicación básica.
   - Botón interactivo para obtener más información.

2. **¿Cómo Funciona? Las 3 Etapas**
   - Descripción de las tres etapas principales del blanqueo de capitales:
     - Colocación
     - Estratificación
     - Integración
   - Animaciones al interactuar con las etapas.

3. **¿Cuáles son las Consecuencias?**
   - Lista de impactos negativos, como daño reputacional, distorsión económica, financiamiento de actividades ilegales, entre otros.
   - Gráfico interactivo que muestra las áreas de impacto.

4. **¿Cómo Prevenirlo?**
   - Medidas clave de prevención, incluyendo:
     - Conoce a tu Cliente (KYC)
     - Reporta Operaciones Sospechosas (ROS)
     - Mantente informado con capacitaciones
     - Realiza debida diligencia continua.
   - Señales de alerta comunes en las transacciones sospechosas.

5. **Marco Legal Relevante**
   - Leyes y normativas aplicables a nivel nacional (Venezuela) e internacional.

6. **Llamado a la Acción**
   - Invitación a registrarse en la próxima capacitación obligatoria.

## Tecnologías utilizadas

- **HTML**: Estructura del contenido.
- **CSS**: Estilos y diseño visual.
  - Uso de fuentes personalizadas de Google Fonts (`Montserrat` y `Open Sans`).
  - Diseño responsivo y uso de animaciones.
- **JavaScript**:
  - Funcionalidad interactiva como modales, animaciones, y gráficos.
  - Uso de la biblioteca [Chart.js](https://www.chartjs.org/) para generar gráficos interactivos.
